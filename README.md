# Content Wall – downloads

Hier staan de versies van de Content Wall-app (Blue Moon) voor Mac.
Download de nieuwste via **Releases** (rechts): `ContentWall-Mac-AppleChip.zip` voor een Mac met Apple-chip, `ContentWall-Mac-Intel.zip` voor een oudere Intel-Mac.

De app zoekt zelf naar updates. Deze repo bevat geen broncode.
